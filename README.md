# One More Inch

A free 3D mobile browser game. Hold to accelerate and release to brake. Stop your ball as close as possible to the cliff edge.

## Play locally on Mac

1. Open Terminal and navigate to this folder (`cd` followed by a space, drag the folder into Terminal, press Return).
2. Run `python3 -m http.server 8000`.
3. Open `http://localhost:8000` in Safari or Chrome.

The game uses the free Three.js library from a CDN, so an internet connection is required.

## Play on iPhone

Publish the `index.html` file using GitHub Pages (free for public repositories) or another static web host, then open the HTTPS link on your iPhone. In Safari, use Share > Add to Home Screen for an app-like icon.

## Controls

Hold the big yellow button to roll. Release to brake. Press Space on a Mac keyboard as an alternative. Press Retry or Next Level after each attempt.

## Costs

No paid assets, accounts, server, or game engine are needed for this prototype. GitHub Pages can host this static game for free. An App Store release would be a separate step.
