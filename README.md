# Sort Rush

A free, single-file mobile browser sorting arcade game. No build tools, paid libraries, external assets, or account needed.

## Play

Open `index.html` in Safari or Chrome, or publish it with GitHub Pages. Tap each colored package before it reaches the bins. Packages must be sent to their matching bin. The symbol on each package matches the bin symbol. Correct sorting builds a combo; a mistake or missed package costs a life.

## Publish on GitHub Pages

1. Create a public GitHub repository named `sort-rush`.
2. Upload `index.html` and `README.md` to the repository root.
3. In Settings > Pages, select Deploy from a branch, `main`, `/(root)` and Save.
4. Wait for deployment and open `https://YOUR-USERNAME.github.io/sort-rush/`.
5. On iPhone, Safari > Share > Add to Home Screen.

## Controls

Tap a package to sort it. On Mac you can also press 1, 2, or 3 to sort the leading package in each lane. The game supports touch and mouse, and saves the high score locally.

## Notes

This is a first playable prototype. It has been checked for syntax and packaged but has not been device-tested on your iPhone. No external dependencies. Free static hosting is available via GitHub Pages for public repositories.
